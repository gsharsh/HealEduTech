# Green and warm palette across the site

## Accomplishments

Student reading, the librarian desk and the administrator workspace use the same sage heading treatment. Account identity, library filters and signed-in work areas use the same palette as Home, Explore and Together. Staff charts retain labelled series and values. Primary actions use rust, and operational warnings and errors retain their own labels and colours. The reading metrics sit together on one warm surface. Help and privacy use a sage contents index, and the error recovery header follows the shared header palette.

## Notes for verification

1. Compare the student reading page and account summary with the librarian desk and administrator settings. Look for a clear heading, readable content, and a primary task that is easy to identify.
2. In the librarian workspace, check that filters, chart legends, counts and follow-up statuses remain distinguishable.
3. On the administrator page, check the navigable sections, controls, and staff access list.
4. Move between Home, Library, Explore, Together, Help and sign-in. Try a narrow screen and switch languages. Check the menu, labels, and action buttons.

Synthetic role fixtures supply the protected views for visual review. User acceptance is recorded separately from automated checks.
