# EVG × HEAL logo

`evg-heal.png` is the user-supplied 1024 × 1024 white-background PNG assembled earlier for the project. It combines the ECO Vietnam Group and Humanitarian Engineers and Leaders marks. The user requested this exact PNG for the website's top-left brand link.

Original sources recorded during preparation: [ECO Vietnam Group](https://ecovietnamgroup.com/), a clearer [EVG logo copy](https://brandfetch.com/ecovietnamgroup.com), and [HEAL's website](https://heal-website.vercel.app/) (`/HEAL%20logo.png`). Placement in this PR does not establish new branding approval; the repository owner should verify the combined mark before publishing.
