# EVG × HEAL logo

`evg-heal-horizontal.png` is the approved website header asset: the ECO Vietnam Group and Humanitarian Engineers and Leaders marks arranged side by side with a small × on white, without the WhatsApp badge's surrounding circle. The 800 × 240 PNG displays at 160 × 48 px on desktop, 112 × 33.6 px on mobile, and 100 × 30 px on narrow phones (up to 360px). The sign-in page uses the same horizontal asset at 220px wide.

`evg-heal.png` retains the earlier 1024 × 1024 square composition for reference; the website header and sign-in page use the horizontal version. Both versions were assembled from the source images, without generative redrawing of the marks. The user approved the smaller horizontal header preview before its inclusion in the PR.

Original sources recorded during preparation: [ECO Vietnam Group](https://ecovietnamgroup.com/), a clearer [EVG logo copy](https://brandfetch.com/ecovietnamgroup.com), and [HEAL's website](https://heal-website.vercel.app/) (`/HEAL%20logo.png`). Placement in this PR does not establish new branding approval; the repository owner should verify the combined mark before publishing.
